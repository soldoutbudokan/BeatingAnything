# NHL anytime-scorer prices versus a normalized multi-book consensus

Declared September 28, 2026, after a price-only inventory of the rebuilt 285-file NHL archive and before any normalization, expected value, selection or target outcome was computed. The inventory found FanDuel `player_goal_scorer_anytime` Yes prices in 273 events covering 9,378 players, 9,166 with at least three other books, and a raw FanDuel-to-median decimal ratio averaging 1.165. FanDuel's implied total is 6.05 per game against 8.12 at Bally, BetRivers and Bovada and 6.0–6.3 at DraftKings, BetMGM and Caesars, so most of that raw gap is bookmaker hold, not information. This card fixes the normalization that separates the two. It is another exploratory comparison in an archive whose goal outcomes were already graded by the shot-to-goal test; it is not an untouched holdout.

**Mechanism:** one-sided anytime-scorer ladders are priced with heavy, book-specific longshot shading, and books shade different players differently. If the other books collectively carry information FanDuel's ladder misses, FanDuel's price for a player will sometimes exceed the consensus fair price by more than FanDuel's own hold. A price-reference screen can test whether such rows win at the quoted price. It cannot show independent forecasting skill, execution or current availability.

## Fixed prices, identities and clocks

Use the rebuilt archive whose manifest is pinned in `tools/rebuild_nhl_shot_archive.py`; every raw payload hash equals its September 26 pin. For each payload with bookmakers, require exactly one `fanduel` node with exactly one `player_goal_scorer_anytime` market. Keep outcomes named `Yes` with a nonblank literal description and a finite American price of absolute value at least 100; drop a book's ladder for that event if any description repeats. Map the literal FanDuel name to an NHL ID through the unchanged unique normalized roster full-name mapping used by the overlap census; unresolved names are excluded and counted. Fixtures follow the same census: unique ordered-team regular-season schedule entry within one day of the provider start, original debug game `2024020345` excluded, boundary equal to the earlier provider or independent start, and the FanDuel market update in the 72 hours strictly before the boundary.

Reference books are every non-FanDuel bookmaker node in the same payload except `ballybet`, which duplicates the Kambi BetRivers ladder. A reference ladder qualifies when it has exactly one anytime market, valid prices, no repeated description, an update strictly before the boundary and within three hours of the FanDuel update. A player's reference requires the exact literal FanDuel description in at least three qualifying reference ladders; no alias, fuzzy or partial matching.

## Fixed normalization and reference

Compute a prior constant `T` once from the pinned 2023–24 `player_box_2024.csv`: regular-season type-02 games that are unique OFF or FINAL entries in the 2023–24 schedule projection, skater rows with position C/L/R/D, positive ice time and valid nonnegative integer goals; `T` is the mean over those games of the number of skaters with at least one goal. Boxscore goals are assumed to include overtime and exclude the shootout. `T` is fixed before any 2024–25 price is normalized and is not tuned.

For each qualifying ladder in an event, with raw implied probabilities `r_i = 1/decimal_i` over its listed players, form two normalized probabilities: proportional, `p_i = r_i * T / sum_j r_j`; and power, `p_i = r_i^k` with `k` solved on [0.25, 4] so that `sum_j p_j = T`, excluding the ladder if no root brackets. Apply both to FanDuel and to each reference ladder. The reference probability for a player is the median across qualifying reference ladders, separately for each method. Ladders listing fewer players are normalized as listed; this is a declared limitation, not a correction to fit.

## Fixed screen, selection and gates

Effective payout is `1 + .98 * (decimal - 1)`. For each method `EV = p_reference * payout - 1`; the score is the smaller of the two. A row qualifies when the FanDuel decimal is within [1.20, 6.00] and the score is at least .03. Select at most one row per game: greatest score, then ascending NHL player ID, then lexical name. Report every qualifying row as a secondary, non-independent tally. Split by boundary at `2025-01-01T00:00:00Z` into the existing early and later periods. Freeze all rows, references, scores and selections with source, code and output hashes before any target join. If there are zero selections, close the screen without target grading.

Grade a selection from the pinned 2024–25 boxscore: a valid positive-ice-time row with consistent integer goals and shots wins iff goals are at least one; a named zero-ice-time row with zero goals and shots is a void; anything else is unknown and retained with adverse and favorable bounds. Compare the game-weighted log loss and Brier score of the power-method reference against FanDuel's own power-normalized probability across all graded reference rows. Use 10,000 game-bootstrap draws with seed 970028, including games with no selection.

An exploratory lead requires later-period reference log loss better than FanDuel's with the 95% lower gain bound above zero, at least 100 settled selected games in each period, positive haircut ROI and positive 95% lower ROI bounds in each period. Passing would still leave a price-reference result: it needs independent validation of the probabilities, current prices and contract terms before it could serve the objective.
