# Expanded QB inventory: prior team attribution

Declared after the source/price inventory and before extracting weekly player metadata or any receiver-role/target-performance values. Ten announcement/price fixtures have an unconditional ceiling of 100 distinct priced players across **both teams**. Opposing players cannot count toward the affected offense's 100-receiver-game gate. Retrospective roster compatibility provisionally assigns only 47 to affected teams, but that is not sufficient prequote membership evidence.

Operationalize the original requirement for prior-observable membership with the player's latest completed 2024 regular-season weekly player record, mapped to an independent fixture whose UTC start plus 72 hours is strictly before that quote. Read only player ID, season, week, season type and team; never target receiving yards, targets, actual starter or target-game participation for this inventory. A player with no unique qualifying prior club remains unresolved. A latest prior club matching the announced offense is a **prior-team proxy**, not proof that a transfer or roster transaction did not occur between games. A latest prior club on the opposing side or another club fails this fixed proxy; preserve those cases explicitly.

For a conservative coverage bound under this proxy, keep unresolved cases as potentially eligible. Do not filter on actual game appearance, receiver results, later injury, position or depth-role values. Report the unconditional both-team ceiling, prior matching-club count, opposite/other-club exclusions and unresolved count separately. If matching plus unresolved falls below 100, the exact priced cohort cannot meet the original sport-side gate under this declared membership proxy; the underlying hypothesis remains unresolved. The proxy assumption and bounded announcement search limit any broader coverage claim.

This adds a deterministic implementation for an already required eligibility check. It does not lower the original gate, choose a performance-favorable cohort, or authorize outcome testing of an insufficient sample.
