## Interpretation

- The McCaffrey 90+ target with a required C40+ base leg is a separate three-leg event. C40+ is not implied by S90+/R<54.5 alone. Only its added C>34.5 leg is the redundancy test; the base condition is labeled in every row.
- S is rushing plus receiving yards; R is rushing yards; C is receiving yards. For an over line, integer final totals give C >= floor(S line)+1−(ceil(R line)−1). For an S milestone such as 50+, use 50 as the minimum combined total.
- Every added leg in the quoted target variants is checked against the base event, including any explicitly required receiving leg. No independence assumption is used.
- FanDuel four-cell SGP prices form the reference partition. OU is S over and R under. Other sportsbooks are excluded.
- Each Score capture uses a complete exact-line FD quartet if one exists, then the nearest FD capture-window midpoint. Otherwise it uses the nearest complete FD quartet with a bound or incomparable label. The summary inherits the best capture’s reference.
- Power chooses k so sum(q^k)=1. Additive subtracts one quarter of the overround from each q; invalid negative probabilities are not clipped.
- Exact lines support a model estimate; a stricter FanDuel event gives a lower bound and a broader event an upper bound. Crossed line changes give no target-EV bound.
- A negative lower bound does not establish negative EV for the broader Score event. A devig model estimate is not an observed win probability.
- Quotes are separate timestamped observations and may have moved between books or variants. Best observed odds do not establish current availability.
- The summary baseline is the nearest base-price capture to the best variant. Not every comparison has an A/B/A repeat, so an observed price difference alone does not isolate repricing from time drift.
- Comparisons condition on common normal completed-game and participation settlement; voids and unusual settlement can differ.
